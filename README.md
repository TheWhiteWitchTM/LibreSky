# LibreSky

LibreSky is a Bluesky client. The app is this page:

https://thewhitewitchtm.github.io/LibreSky/

Open that address. If you are not signed in, the page starts on a sign-in screen and then keeps that sign-in in this browser until you sign out. Create an account from that screen if you do not have one yet. Bluesky’s own page handles the password. Home, Discover, search, notifications, chat, bookmarks, feeds, lists, profiles, and posts come from your Bluesky account.
